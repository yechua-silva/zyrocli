🔑 Hallazgos clave

  1. ZyroCLI es el ÚNICO que genera tests automáticos con cobertura 66-82%. Plain y gentle-ai generan 0% cobertura en todas las iteraciones.
  2. ZyroCLI refactoriza el código en múltiples archivos (2-3 archivos vs 1 archivo de los otros). Código más modular.
  3. Plain OpenCode es el más rápido y barato pero produce código sin tests ni estructura.
  4. gentle-ai tiene el mayor consumo de tokens en sesiones avanzadas (+45% tokens input respecto a Plain en sesión 3).
  5. ZyroCLI sufre timeouts en tareas complejas (3/9 runs). El Boomerang de 6 pasos es más lento pero el código es de mayor calidad.
  6. La diferencia de costo es marginal ($0.002 vs $0.0025 promedio). DeepSeek V4 Flash es tan barato que el costo no es factor diferenciador.

🔬 Metodología

  • 3 sesiones incrementales: Sesión 1 = JWT auth, Sesión 2 = roles, Sesión 3 = refresh token
  • 3 iteraciones por jaula × sesión = 27 runs total (24 completados)
  • Medición exacta: opencode export para tokens, go test -cover para cobertura
  • Modelo: DeepSeek V4 Flash vía OpenCode Zen (gratis, sin API key)
  • Timeout: 900s por run (15 min). ZyroCLI tuvo 3 timeouts en sesiones 2-3
