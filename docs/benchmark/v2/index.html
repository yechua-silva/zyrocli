🔧 Cuello de botella del Boomerang (ZyroCLI)

⚠️ Problema detectado: El Boomerang ejecuta 6 pasos secuenciales por fase (Memory → Think → Delegate → Git Check → Quality Gates → Save Memory).

Impacto:
  • Tiempo no medible directamente (ZyroCLI no reporta time_elapsed_s) pero por logs se estima 2-3× más lento que Plain
  • Timeouts en sesiones complejas: 3/9 runs (sesiones 2-3 con roles + refresh)
  • Razonamiento extra en fases de planificación y verificación
Por qué existe: El Boomerang fue diseñado para proyectos grandes donde el overhead de planificación se paga con creces al evitar errores costosos. Para tareas chicas como este benchmark (1 API Go), el overhead es desproporcionado.

Mejora planeada: Optimizar el Boomerang para que pueda saltar pasos cuando la tarea no los requiere (Smart Boomerang). Por ejemplo, si no hay cambios en el repo, saltar GitStep. Si no hay tareas delegadas, saltar DelegateStep.

✅ Conclusión honesta

📊 Lo que dicen los datos (24 runs, 3 sesiones incrementales):
  1. ZyroCLI produce mejor calidad — es el único que genera tests automáticos con cobertura real (0-82%) y código modular en archivos separados. El QualityStep del Boomerang fuerza compilación y verificación de calidad.
  2. ZyroCLI gasta menos tokens input que gentle-ai (−35% en sesión 1) y comparable a Plain. La memoria causal inyecta contexto filtrado, el agente no pierde tokens explorando en exceso.
  3. ZyroCLI es significativamente más lento que Plain y gentle-ai. El Boomerang tiene overhead real en tiempo y en timeouts (3/9). Para tareas pequeñas no conviene; para proyectos grandes el overhead se amortiza en calidad.
  4. Plain OpenCode es óptimo para tareas rápidas (1-2 archivos, sin tests). Rápido, barato, consistente. Pero no genera tests ni código modular — produces deuda técnica.
  5. gentle-ai es consistente pero caro en tokens (+31-90% tokens input vs Plain y ZyroCLI). 100% tasa de éxito, pero usa agentes tipo "zyro-sdd-*" que gastan tokens en metadatos de HelixDB.
  6. El costo no es factor diferenciador — DeepSeek V4 Flash es tan barato que las diferencias son centavos. Con modelos caros (GPT-4, Claude), la historia sería otra y ZyroCLI sería más caro por el overhead de tokens de planificación.
